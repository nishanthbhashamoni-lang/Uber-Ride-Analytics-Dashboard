# Uber Ride Analytics Dashboard 🚕📊

## Project Overview
An interactive Power BI dashboard built to analyze Uber ride booking data and gain insights into ride performance, customer behavior, revenue, and cancellations.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Key Insights
- Total Completed Bookings
- Lost Bookings
- Total Distance
- Revenue Analysis
- Average Customer Rating
- Average Driver Rating
- Ride Status Analysis
- Monthly Booking Trends
- Vehicle Type Analysis

## Dashboard Features
- Interactive filters
- Monthly and quarterly analysis
- KPI cards
- Customer and driver ratings
- Ride cancellation analysis
